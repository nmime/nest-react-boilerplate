# @app/backend-feature-auth-shared

## Purpose

Defines session and principal contracts, access-policy defaults, bearer guards,
RBAC decorators, tenant context, and OAuth/OIDC provider flows.

## Commands

```bash
pnpm exec nx run @app/backend-feature-auth-shared:build
pnpm exec nx run @app/backend-feature-auth-shared:test
```
