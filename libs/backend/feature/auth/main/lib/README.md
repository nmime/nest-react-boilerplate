# @app/backend-feature-auth-main

## Purpose

Owns registration, login, session lifecycle, current-user, logout, and external
authentication orchestration behind the auth Nest module and HTTP controller.

## Commands

```bash
pnpm exec nx run @app/backend-feature-auth-main:build
pnpm exec nx run @app/backend-feature-auth-main:test
```
