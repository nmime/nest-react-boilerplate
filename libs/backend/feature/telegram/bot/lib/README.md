# @app/backend-feature-telegram-bot

## Purpose

Implements the grammY bot runtime, localized menus, session and navigation
state, Mini App launch actions, identity resolution, and account linking.

## Commands

```bash
pnpm exec nx run @app/backend-feature-telegram-bot:build
pnpm exec nx run @app/backend-feature-telegram-bot:test
```
