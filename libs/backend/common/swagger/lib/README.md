# @app/backend-common-swagger

## Purpose

Centralizes Swagger/OpenAPI document setup, bearer security, operation
decorators, schema helpers, and standard Problem Details responses.

## Commands

```bash
pnpm exec nx run @app/backend-common-swagger:build
pnpm exec nx run @app/backend-common-swagger:test
```
