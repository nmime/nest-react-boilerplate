# @app/frontend-ui-native

## Purpose

Provides the Tamagui configuration, design-token themes, provider exports, and
native UI foundation consumed by Expo applications.

## Commands

```bash
pnpm exec nx run @app/frontend-ui-native:test
pnpm exec nx run @app/frontend-ui-native:build
```
