# @app/backend-feature-user-shared

## Purpose

Defines user profile and permission contracts, the current-profile use case,
normalization helpers, and presenter shapes shared across user APIs.

## Commands

```bash
pnpm exec nx run @app/backend-feature-user-shared:build
pnpm exec nx run @app/backend-feature-user-shared:test
```
