# @app/backend-feature-user-main

## Purpose

Exposes the authenticated profile HTTP controller and composes the user feature
module from shared profile contracts and persistence-backed providers.

## Commands

```bash
pnpm exec nx run @app/backend-feature-user-main:build
pnpm exec nx run @app/backend-feature-user-main:test
```
