# @app/backend-feature-discord-bot

## Purpose

Implements Discord signature verification, command registration, interaction
routing, navigation state, localized menus, and external-account linking.

## Commands

```bash
pnpm exec nx run @app/backend-feature-discord-bot:build
pnpm exec nx run @app/backend-feature-discord-bot:test
```
