# @app/common-design-tokens

## Purpose

Defines renderer-neutral color, spacing, radius, typography, and theme tokens
consumed by the web CSS and native Tamagui facades.

## Commands

```bash
pnpm exec nx run @app/common-design-tokens:build
```
